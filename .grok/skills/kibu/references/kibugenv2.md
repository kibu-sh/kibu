# kibugenv2 artifacts

Writes `<pkg>.gen.go` in the same package as the spec. Header: `// Code generated by kibu. DO NOT EDIT.`

HTTP uses `pkg/transport/httpx`, not gin.

## From a workflow interface `Foo`

| Symbol | Role |
|--------|------|
| `FooRun` | Client handle: `Get`, signals, queries, updates |
| `FooChildRun` / `FooExternalRun` | Child / external workflow handles |
| `FooClient` | `Execute`, `GetHandle`, `ExecuteWith<Signal>` |
| `FooChildClient` | Call from another workflow |
| `FooInput` | Request plus generated signal channels |
| `FooFactory` | `func(input *FooInput) (Foo, error)` — provide this |
| `FooController` | Registers the workflow; field `Factory FooFactory` |
| `New<Signal>SignalChannel` | Channel constructor |

Package-level `WorkflowsClient` / `WorkflowsProxy` index every workflow in the package. `NewWorkflowsClient` and `NewWorkflowsProxy` are generated providers.

## From an activity interface

`ActivitiesProxy` (call from workflows), `ActivitiesController` (field `Activities Activities`). Provide `NewActivities`.

## From a service interface

`ServiceController` with `HTTPHandlerFactory` (`group=HandlerFactory`). Provide `NewService`.

## Worker

`WorkerController` (`group=WorkerFactory`) builds a Temporal worker from the activity and workflow controllers.

## Constants

Qualified names like `billingv1.Service.WatchAccount` are generated for registration. Use those; do not invent parallel name strings.
